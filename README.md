### 신규 구현 시 주의 (실제로 겪은 클래스 충돌)
새 CSS 클래스는 **기존 클래스와 충돌**하기 쉽다. 아래는 실제 충돌 사례다.
- `.mv-head` — 멀티뷰 타일 헤더(`position:absolute`)와 충돌 → 메뉴 화면은 **`.mn-*`** 접두사 사용
- `.rep` — 유사 대상별 보기 대표 카드(`width:180px`)와 충돌 → AI 보고서는 **`.csrep`**, 인물 관리 썸네일은 **`.is-rep` / `.b-rep`** (같은 함정 2회 발생)
- `CASES` / `CASE_KINDS` — 사건 등록 팝업용으로 **이미 존재** → 신규는 **`CASE_DB` / `CS_KINDS` / `CS_STATUS`**
- ✅ `CASE_STATES` **3종으로 통일**(2026-08-25) — 사건 등록 팝업도 신규 사양(`처리전·진행중·처리 완료`)에 맞춤. 기존 `보류`는 사양에 없어 제거
