### 시안 검토용 스위치 위치
`AI 있음|AI 없음` · `A안|B안` 스위치는 **윈도우 탭 옆(좌측, `+` 다음)** 으로 옮겼다.
시안 판단을 방해하지 않도록 `opacity:.28` 로 흐리게 두고 **hover 시에만 또렷**해진다.
활성 표시도 파랑/보라 대신 중성 회색(`rgba(255,255,255,.13)`)이다.
→ 덕분에 윈도우 크롬 우측이 시안과 동일하게 `AI pill · 알림 · 프로필 · 최소/최대/닫기` 만 남는다.
