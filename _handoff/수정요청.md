# 수정요청

사용자가 준 수정사항을 **원문 그대로** 옮긴 파일이다. 요약·재해석하지 않았다.
작업 세션은 `git pull` 로 최신을 받아 아래 원문을 읽고 반영한다.

- 화면 확인: `index.html#demo=<값>` — 값 목록은 `README.md` §상태 딥링크
- 반영 후:

```sh
git add -A && git commit -m "수정요청 반영 — <요약>"
git pull --rebase && git push
```

- 원문이 애매하면 추측하지 말고 해당 항목 아래에 `❓` 로 질문을 적어 두고 push 한다.
- 이 파일의 **원문 부분은 작업 세션이 고치지 않는다.** 처리 결과는 각 항목 아래에 덧붙인다.

## 원문

### 2026-09-01 · 1차

1. 타임라인
 - 탐지이력 타이틀 삭제하고 편집 버튼 위치를 조정하여 공간 확보
 - 타임라인은 배치되는 영상 클립들의 전체 시간을 모두 표시함 
 - 타임라인의 배율을 조정하는 버튼 사양 추가
 - 타임라인에는 시간외에 날짜 표시사양도 들어가야 하며 날짜 변경되는 시점에 날짜를 표시한다
 - 클립 길이를 나타내는 바의 두께는 가독성을 유지한 수준에서 얇게 표시하여 상하 공간을 최대로 확보
 - 클립별 번호 라벨은 바에서 영상클립 썸네일 이미지 쪽으로 이동
 - 재생 툴바 버튼 디자인 배열 수정 (에스원 기준으로 변경, 좌우 이동버튼은 양쪽에 유지, 음량 조정 버튼은 설정으로 이동)
 - 여러 인물을 동시 비교 시 2개-3개-4개 트랙으로 비교대상 인물 수에 따라 최대 4개 트랙으로 타임라인에 표시 가능.
 - 모든 인물별 타임라인 바는 썸네일 상시표시(접기 옵션 없음), 썸네일은 타임라인 바 (좌우폭) 사이즈를 따르며 바가 타임커서가 지나가거나 호버시 해당 썸네일을 크게 표시한다. (주변 썸네일 위로 오버해서 표시)
 - 경로비교 시 타임라인 패널의 높이는 1~4개의 트랙 갯수에 따라 달라지며(상하스크롤이 생기지 않는 높이까지) 그에 따라 상단의 영상표시 영역의 상하폭이 조정된다.
 - 하나의 타임바에 여러개의 영상 클립이 있을 수 있고 (한 장소에 여러개의 카메라가 있는 경우) 이 경우 대표 썸네일만 표시하고 몇 개의 썸네일이 있는지 표시(겹침표시 또는 갯수 표시)
 - 위 경우 영상영역에 재생되는 영상 우측 하단에 PIP 형태로 나머지 영상들이 작게 재생되고 선택 시 메인 영상과 스위칭 되어 크기가 변경됨(이 경우 메인으로 재생되는 영상의 썸네일이  타임라인에 표시됨)

2. 타임라인 편집
 - 편집 모드 진입 시 RE-ID 이후 동선 구성을 위한 영상 클립 선택이 가능해야 함 (앞서 도출한 목록을 다시 불러와 재선택 가능하도록)
 - 편집모드 진입 시 타임라인 위에 있는 썸네일을 좌우로 영역을 지정하여 클립 길이를 조정할수 있어야 함. (아이폰 영상 편집 기능이나 맥의 imovie와 비슷한 방식의 클립 편집 방식. (자르기는 없고 범위 조정만 가능한 형태)

## 처리 결과 · 2026-09-01 1차

타임라인을 새로 만들어 상세 화면과 경로 비교에 함께 적용했다.
(`renderTimeline()` + `TL_TRACKS` 데이터. 기존 눈금/세그먼트/클립 스트립은 `dt-hist-legacy` 로 숨김)

| # | 요청 | 처리 |
|---|---|---|
| 1 | 탐지이력 타이틀 삭제 · 편집 버튼 위치 조정 | 타이틀 제거, 편집 버튼을 타임라인 상단 **배율 옆(우측)** 으로 이동 |
| 2 | 클립 전체 시간 표시 | 클립에 절대 시각(from/to)을 부여하고 전체 구간을 감싸 그린다 (하루 고정 눈금 폐기) |
| 3 | 배율 조정 버튼 | `− / 1x / +` (1~8배). 배율에 따라 눈금 간격이 5분~12시간으로 자동 조정 |
| 4 | 날짜 표시 | 눈금을 2단으로 나눠 위=날짜 / 아래=시각. **날짜가 바뀌는 지점**에만 날짜를 적는다 |
| 5 | 클립 바 얇게 | 5px 로 축소해 상하 공간 확보 |
| 6 | 번호 라벨을 썸네일로 | 바에서 빼고 썸네일 좌상단으로 이동 |
| 7 | 재생 툴바 배열 | 좌우 이동 버튼은 양 끝 유지, 안쪽에 10초·배속·재생/일시정지 대칭. **음량은 설정 팝업으로 이동** |
| 8 | 2~4 트랙 비교 | 비교 인원 수만큼 트랙 생성 (최대 4) |
| 9 | 썸네일 상시 표시 · 확대 | 접기 없음. 폭은 바 폭을 따르고 **타임커서가 지나가거나 호버**하면 1.4배로 주변 위에 표시 |
| 10 | 트랙 수에 따른 패널 높이 | `34 + 트랙수 × 112 + 32` px. 스크롤이 생기지 않는 높이이며 그만큼 위 영상 영역이 줄어든다 |
| 11 | 한 바에 여러 클립 | 대표 썸네일만 두고 우상단에 `+N` 개수 배지 |
| 12 | PIP | 영상 우하단에 나머지 카메라를 작게 재생. 누르면 메인과 스위칭되고 타임라인 썸네일도 메인을 따라간다 |

### 판단해서 정한 것
- **확대 배율 1.4배** — 1.55배로는 트랙 높이를 넘어 썸네일이 잘렸다. 트랙 112px 안에 들어오는 값으로 조정
- **트랙 높이 112px** — 확대된 썸네일(56 × 1.4 = 78px)이 잘리지 않는 최소치
- **상세 화면은 1트랙** — 단일 대상이므로. 비교 화면에서만 2~4트랙

### ❓ 확인 필요
- **PIP 위치·개수** — 지금은 우하단에 최대 2개를 가로로 뒀다. 개수가 더 늘면 접거나 세로로 쌓아야 하는데 사양이 없다
- **타임커서 이동 수단** — 지금은 클립을 누르면 그 구간 가운데로 커서가 간다. 눈금을 직접 끌어 이동하는 동작이 필요한지
- **편집 모드와 새 타임라인의 관계** — 편집(클립 삭제/추가)은 기존 스트립 기준이라 새 타임라인에는 아직 연결하지 않았다
  → **2차 요청이 이 건을 다룬다.**
