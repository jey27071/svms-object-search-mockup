# 수정요청

사용자가 준 수정사항을 **원문 그대로** 옮긴 파일이다. 요약·재해석하지 않았다.
작업 세션은 `git pull` 로 최신을 받아 아래 원문을 읽고 반영한다.

- 화면 확인: `index.html#demo=<값>` — 값 목록은 `README.md` §상태 딥링크
- 반영 후:

```sh
git add -A && git commit -m "수정요청 반영 — <요약>"
git pull --rebase && git push
```

- 원문이 애매하면 추측하지 말고 해당 항목 아래에 `❓` 로 질문을 적어 두고 push 한다.
- 이 파일의 **원문 부분은 작업 세션이 고치지 않는다.** 처리 결과는 각 항목 아래에 덧붙인다.
