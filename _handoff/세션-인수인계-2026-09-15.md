## 2. 반드시 지킬 규칙

1. **답은 한글로만.** 중간 진행 안내도 한글.
2. **사용자 구두 지시 = 확정 사양.** 사양서(Figma `dUk79DU8nwk3afINPckgOI`)와 어긋나도 지시대로 만들고, 어긋난 점은 **되묻지 말고** `_handoff/사양서-수정필요-목록.md` 에 표로 기록.
3. 지시가 없는 부분 : **동작 = 사양서 / 디자인 = GUI 시안**(Figma `Tnihi6lixRR47N4RSAwUbF`).
4. **요청이 3개 이상이면 청크로 나눠** 하나씩 구현 → 확인 → 커밋. 작업 중 새 요청이 끼어들면 대기열에 넣고 순서대로.
5. **UI 문구는 받아적지 말고** 맞춤법·앱 표기에 맞게 고쳐 넣고 무엇을 고쳤는지 알린다 (예: `층이동` → `층 이동`).
6. **정리는 삭제 대신 아카이브.** 필요 없는 버튼은 CSS 로 숨기고 코드는 남긴다 (예: 탭 줄 `＋`).
7. 커밋 메시지 끝에 반드시:

8. URL 을 사용자에게 열어 보일 땐 `open -a "ego lite" <url>` (Playwright 자동화는 별개).

## 4. 작업 절차 (매 청크)

1. 필요한 코드·CSS 위치를 `grep -n` 으로 찾고 해당 부분만 읽는다.
2. 수정 (JS 는 정확 문자열 치환, CSS 는 파일 끝에 주석과 함께 추가).
3. `node --check assets/js/app.js` (map3d.js 를 고쳤으면 그것도).
4. **실제 Chromium 으로 확인** — `tools/qa/` 스크립트를 복사·수정해 수치(위치·크기·색)와 캡처를 뽑고, 캡처를 직접 본다.
5. `_handoff/사양서-수정필요-목록.md` 에 결정 사항 표 추가.
6. `./tools/bust.sh && git add -A && git commit -m "…" && git push origin main`
7. 사용자에게 한글로 무엇을 왜 바꿨는지, 시안과 다르게 둔 것, 확인 못 한 것을 보고.

## 7. 알고 있어야 할 함정

- **CSS 우선순위** : 앞쪽 `#sidePanel` `#preview` 같은 ID 규칙이 뒤에 붙인 클래스 규칙을 이긴다. 안 먹으면 `getComputedStyle` 로 확인하고 ID 를 넣어 올릴 것. `.acc.open[data-acc="cam"] …` 같은 속성 선택자도 셈.
- **범위 한정** : 검색 홈 전용은 `body:not(.in-detail)`, 상세 전용은 `body.in-detail` / `body.dt-b`. 패널 접힘은 `body.side-folded`.
- `.tl-th`(클립)은 `overflow:hidden` — 밖으로 그리는 장식은 잘린다. 클립 편집 틀은 클립 안쪽에 그렸다.
- 지도 판 안의 `.zm-stage img` / `.zp-stage img` 는 **판 전체를 채우는 규칙** → 판 안에 넣는 미리보기 이미지는 따로 풀어 줘야 한다.
- 분할 ↔ 단일 전환은 `setViewMode` 가 `#dtVideo.has-multi` 를 관리한다(빠지면 조작 바가 위로 붙음).
- 경로 비교 칸 `pipSwap` 은 `.cmp-vid > img` 를 메인 이미지로 찾는다(PIP 는 칸 직계).
- 3D 는 headless 에서 `--use-gl=swiftshader` 가 있어야 캔버스가 뜬다.
- `git push` 가 느릴 수 있다(끊긴 게 아님).
- 저장소·Pages 가 **Public** — 에스원 브랜딩·CCTV 이미지가 공개 중. 비공개가 필요해지면 Pages 끄기/비밀번호 보호 필요.
