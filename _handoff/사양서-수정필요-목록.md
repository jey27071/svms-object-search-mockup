## 4. 사양서에 정의가 없어 목업이 임의 구현한 것 (§17)

확정되면 목업을 맞춘다.

- 하단 상태바 `조치필요` 버튼의 동작
- 지능형 알고리즘 목록 (목업은 임의 10종)
- AI 에이전트 추천 질문 3개가 고정인지 동적인지
- AI 추천 후속 **액션**의 종류 (목업은 안내 토스트만)
- 첨부파일의 용도 (업로드 후 무엇을 하는지)
- 무결성 검증(SHA-256) 주체·시점
- GUID 발급 주체·규칙 ("이미지 등록 시 자동 부여"만 정의)
- 고유 사건번호 채번 규칙
- 설치 구역 목록의 출처 시스템
- 카메라 좌표 저장 방식(상대/절대), 이미지 교체 시 기존 좌표 처리
- 검색 히스토리·최근 검색어 저장 위치(서버/로컬)
- `오탐지 신고` 후 처리 흐름
- 맵 미등록 상태에서 맵뷰어·이동 경로 동작

## 6. 2026-08-31 개편 — 제가 판단해 정한 것

사용자가 자리를 비운 사이 진행하며, 사양에 정의가 없어 **제 판단으로 결정**한 항목이다.
확인 후 다르면 되돌리면 된다.

| # | 항목 | 결정 | 근거 |
|---|---|---|---|
| 1 | **관심인물 알림** | 알림 **버튼(수신 UI)만** 제거하고 관심인물 등록·관리와 알림 설정 화면은 유지 | 지시는 '알림 버튼 삭제' 였고 관심인물 기능 자체를 빼라는 말은 없었다. 최소 변경 |
| 2 | **카메라 `전체` 의 의미** | 빈 배열이 아니라 **전체 카메라를 담는다** | 기존엔 '전체 체크 = 미선택' 이라 '카메라 선택 필수' 규칙과 모순이었다 |
| 3 | **첫 진입 카메라** | 저장값이 없으면 **전체 선택**으로 시작 | 필수 규칙을 지키면서 첫 진입에서 막히지 않게 |
| 4 | **자연어 색상 다중 언급** | 문장의 색상어를 모두 뽑아 상의 색상 필터에 반영, **OR** 로 처리하고 토스트로 알림 | 사용자가 필터에서 바로 고칠 수 있어 되돌리기 쉽다 |
| 5 | **검출 인물 이름 규칙** | `인물 01`, `인물 02` … (2자리 0채움) | 정렬이 자연스럽고 자릿수가 일정 |
| 6 | **최근 검색 노출** | 입력창을 **선택했을 때만** 아래로 펼침 (텍스트·차량 동일) | 상시 노출은 필터를 밀어내고 검색 후에도 남아 방해됐다 |
| 7 | **RE-ID 진입** | 결과 카드 **더블클릭** | 1클릭은 기존대로 미리보기. 클릭 한 번에 큰 팝업이 뜨면 오조작이 잦다 |
| 8 | **클립 1차 호출 수** | 12개, `더보기` 로 추가 | 사양은 '사용자가 설정한 최대 갯수' 인데 설정 UI가 없어 기본값으로 둠 |
| 9 | **분리 상태의 접기 핸들** | 감춘다 | 패널이 떠 있어 핸들을 붙일 가장자리가 없다 |

### 아직 확인이 필요한 것
- **관심인물 알림의 최종 사양** — 위 1번 결정이 맞는지, 기능 자체를 뺄지
- **클립 최대 개수 설정 위치** — 환경설정에 둘지, 팝업 안에 둘지
