## 6. ★ Figma 작업 함정 (이전 세션에서 실제로 겪은 것)

1. **`clone()` 은 부모가 PAGE로 붙는다** → 반드시 `section.appendChild(node)` 후 `node.x/y` 재설정. 안 하면 그리드에서 사라진 것처럼 보임.
2. **텍스트 수정 전 폰트 로드 필수.** `characters` 뿐 아니라 `textAutoResize` 만 만져도 에러.
   ```js
   const fs = node.getRangeAllFontNames(0, node.characters.length);
   for (const f of fs) await figma.loadFontAsync(f);
   node.characters = '...';
   ```
   시작 시 `for (const s of ['Light','Regular','Medium','SemiBold','Bold']) await figma.loadFontAsync({family:'Pretendard', style:s})`
3. **두톤 제목**은 `setRangeFills(0, kw.length, [blue])` + `setRangeFills(kw.length, all, [dark])`
4. **중첩 오토레이아웃 안의 FILL 텍스트는 폭이 붕괴해 "한 글자씩 세로줄"로 깨진다.** 표·정보밴드는 **오토레이아웃 대신 고정좌표**로 그릴 것 — 배경 `createRectangle()` + 텍스트 `createText()` + `resize(고정폭, h)` + 절대 x/y.
5. **`getNodeByIdAsync`** 사용(동기 `getNodeById` 는 null). 페이지 전환은 `await figma.setCurrentPageAsync(page)`.
6. `figma.notify()` 는 미구현 — 쓰지 말 것. 결과는 `return` 으로만 확인.
7. 텍스트 폭 미지정 시 한 줄로 뻗음 → 랩핑 필요하면 `textAutoResize='HEIGHT'` **먼저** 지정하고 `resize(width, h)`.
