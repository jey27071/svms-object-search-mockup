## 1. 북마크 (Bookmark_001_01 / _02)

### 레이아웃
좌측 목록 ≈1115px(카드 2열) / 우측 상세 ≈800px

### 1-1. 목록 영역
- 검색: 북마크에 추가된 **인물명/위치명**으로 조회
- 필터 칩: `전체 | 대상 | 영상` (Default `전체`)
- `총 N` / 0건 문구: **`북마크한 항목이 없습니다.`**
- 정렬: **북마크 등록 일시 최신순 자동**
- **영상 카드**: 대표 썸네일, **영상 길이 태그(`10초`)**, 위치명, 대상명, 촬영 일시, 북마크 버튼
- **대상 카드**: 인물 대표 썸네일, 대상명, **GUID**(없으면 `-`), 북마크 버튼
- 카드 선택 → 활성화 + 우측 상세 로딩
- 북마크 버튼 선택 → 표시 해제, **새로고침/재진입 시 목록에서 제거**

### 1-2. 북마크 상세 — 영상 선택 시
- 타이틀 `북마크 상세` + 버튼 `원본 보기` / `편집` / `사건 등록`(primary)
  - 원본 보기 → 원본 영상 상세화면으로 이동(**검색 메뉴로 이동 + 새 탭**)
  - 편집 → `북마크 편집`으로 전환
  - 사건 등록 → 사건 등록 팝업(대상·영상 자동 첨부)
- 영상 플레이어 + **무결성 검증 Chip**(`원본 무결성 SHA-256 검증 완료`, 우측 상단, 초록)
- 재생바: 현재 시점, 10초 뒤로/앞으로, 배속 뒤로/앞으로, 일시정지, 재생, 음량
- 정보: 대상 / 위치 / 카메라명 / 출현 일시 / **메모**(예: `용의자 최초 포착 지점`)

### 1-3. 북마크 편집 (편집 버튼)
- 타이틀 `북마크 편집` + `취소` / `완료`
  - 취소: 변경 없으면 즉시 종료, **변경 있으면 `편집 취소 alert`**
- 영상: **원본 전체 영상** 노출 + 무결성 Chip
- **타임라인 바**: 북마크 저장 구간 재설정, 설정 구간 하이라이트, 현재 재생 위치 인디케이터
  - 시간축 예시 `11:00 ~ 17:00`
- 정보: 대상·위치명·카메라명·출현 일시 **Read-only**, **메모만 수정 가능**

### 1-4. 북마크 상세 — 대상 선택 시
- 버튼: `원본 보기`(최초 포착 원본 영상 상세) / `사건 등록` (편집 없음)
- `이미지 (N)` 대표 썸네일 — **복수 클립이면 최초 출현 영상 스냅샷을 대표로 자동 노출**
- 대상 정보: 대상명, **GUID**(없으면 `-`), 최초 출현 일시, 색상(상의/하의)

## 2. 사건 관리 (Case_001 / 002 / 003 / popup_01 / popup_02)

### 레이아웃
좌측 목록 ≈230px(좁음) / 우측 상세 나머지

### 2-1. 사건 목록
- 타이틀 `사건 목록` + `사건 등록` 버튼(선택 시 우측이 **사건 등록 영역**으로 전환)
- 검색: 사건명 키워드
- **상태 필터**: `처리전 / 진행중 / 처리 완료` 중 택1
- **기간 필터**: 사건 등록일 기준, Default `당일` (당일/최근3일/최근7일/날짜지정+date·time picker)
- `총 N개` / 0건 문구: **`등록한 사건이 없습니다.`**
- **정렬: 처리 상태(`진행중 > 처리전 > 처리 완료`) 1차 → 동일 상태 내 등록 일시 최신순**
- 사건 카드: 사건명, **처리 상태 Chip**, 작성일, 대상 수, 증거 수 (`2026-00-00 · 대상 4 · 증거 3`)

### 2-2. 사건 상세
- 타이틀: 사건명 + 상태 Chip + 작성일 / 사건 분류 / 발생 시작~종료 일시 / 상세 설명
- 버튼: `삭제`(→ 사건 삭제 alert) / `편집`(→ 편집 모드) / **`내보내기`**(primary)
  - 내보내기: AI 보고서 + 모든 증거 자료(대상 정보·영상 클립) 패키징 → **ZIP 또는 리포트 파일 일괄 다운로드**
- **`✦ AI 생성 보고서`** (아코디언): 제목(사건명·고유 사건번호·처리 상태·최초 등록일) +
  `1. 사건 개요` `2. 이동 경로 (카메라 순)` `3. 증거 자료` `4. 조치 의견`
  - 예시 본문은 사양서에 전문이 있음 → 목업 데이터로 그대로 사용
- **`대상 정보 (N)`** (아코디언): 등록/추가 순 정렬. 카드 = 썸네일, 대상명, 출현 일시, **감지 이벤트명(없으면 `-`)**, 색상
- **`증거 영상 (N)`** (아코디언): 대상 추가 시 해당 대상 포착 클립 **자동 수집**, 촬영 일시 시간순 자동 정렬
  - 카드 = 대표 썸네일, **무결성 Chip(검증 실패 시 미노출)**, 위치명, 촬영 일시, 카메라명, 관련 대상명, `원본 영상 보기`
- **`이동 경로`** (아코디언): 맵뷰어(출현 지점·위치명·이동 경로) + **구역 드롭다운**(`A동 (1건)` 형식: 구역명 + 탐지 지점 수) + `전체 보기`(맵뷰어 전체보기 팝업) + 출현 지점 레전드(대상별 색상 점) + **시간순 이동 경로 리스트**(맵 포커스 항목 활성화)

### 2-3. 사건 편집 (Case_003)
- 타이틀 `사건 수정` + `취소`(변경 시 편집 취소 alert) / `저장`
- **`사건 등록` 버튼 비활성화** (편집 중)
- 입력: 사건명*, 상태*(처리전/진행 중/처리 완료), **분류\*(도난/침입/배회/폭행)**,
  사건 시작/종료 일시*(**date picker + time picker, 종료는 시작 이후만**), 설명*
- **연계 대상 관리: 최대 4개** — 헤더 `대상 정보 (N/4)`, `대상 추가` 버튼(4개면 비활성),
  카드 `X` → **인물 삭제 alert**
- **증거 영상 관리**: `영상 추가` 버튼(→ 영상 추가 팝업), `원본 영상 보기`(→ 영상 전체보기 팝업), `삭제`(→ 영상 삭제 alert)
- 이동 경로: 안내문구 **`추가한 대상과 영상 정보에 맞춰 경로가 자동으로 구성됩니다.`**

### 2-4. 대상 추가 팝업 (Case_003_popup_01)
- 타이틀 `대상 추가` / 안내 `사건과 연관된 대상을 추가하여 함께 관리할 수 있습니다.`
- `X`·`취소`: 선택 없으면 즉시 종료, **선택 있으면 `등록 취소 alert`**
- 탭: `검색`(Default) / `북마크`
- 검색 탭: 자연어 검색 입력 + 필터(**위치 / 색상(대상 유형별 상이: 인물=상의·하의, 차량=별도) / 기간**(Default 당일))
  - 검색 전 안내 `검색어를 입력해 주세요.` / 검색 후 `총 N`
- 북마크 탭: 없으면 **`북마크한 대상이 없습니다.`**
- `추가` 버튼: 미선택 시 **비활성**

### 2-5. 영상 추가 팝업 (Case_003_popup_02)
- 타이틀 `영상 추가` / 안내 `추가된 대상 또는 북마크한 영상을 사건 증거 자료로 등록할 수 있습니다.`
- 탭: `대상`(Default) / `북마크`
- **`총 N건 선택`** — **탭 전환 시에도 선택 누적 유지(초기화 금지)**
- 목록: 그룹 헤더 아코디언, `대상명 (선택 수 / 총 영상 수)` 태그 (예 `인물 A* 1/6건`)
  - `*` 표시 대상: 안내 **`선택 시 인물이 대상 정보에 자동으로 추가됩니다.`**
  - 영상 카드: 체크박스, 대표 썸네일, 포착 위치, 일시
  - 영역 초과 시 내부 세로 스크롤
- `추가`: 미선택 시 비활성

## 3. 맵 관리 (Map_001 / 002_01 / 002_02 / 003)

### 3-1. 맵 목록 (Map_001)
- 타이틀 `맵 목록` + `맵 등록` 버튼(→ 우측이 맵 등록 영역으로 전환)
- `총 N개` / 0건: **`등록한 맵이 없습니다.`** / 등록 일시 최신순 / 최초 진입 시 최신 자동 선택
- 카드: 맵 이름 (`A동 지도`, `B동 지도` …)

### 3-2. 맵 상세
- 타이틀 `맵 상세` + `삭제`(→ 맵 삭제 alert) / `편집`
- 기본 정보: **이름 / 위치 / 배치 카메라 리스트**(`카메라 (7)` + 텍스트 리스트)
- 맵 이미지 뷰어: 업로드 원본을 영역 비율에 맞춰 노출, **카메라 아이콘 + 아이콘 하단 위치명**

### 3-3. 새 맵 등록 (Map_002_01 → _02)
- 타이틀 `새 맵 등록` + `취소`(입력 있으면 등록 취소 alert) / `등록`(**필수값 전부 입력 시 활성**)
- 입력: **이름\*** (`맵 이름`), **위치\*** (기등록 구역 드롭다운, `위치 선택`), **카메라\***
  - 위치 선택 **전** 안내: **`위치를 선택하면 해당 위치의 카메라가 자동으로 표시됩니다.`**
  - 위치 선택 **후**: 해당 위치 카메라 목록 표기 + **초기화 버튼**(1개 이상 선택 시 활성)
- 이미지*: 드래그앤드롭 또는 `이미지 선택`
  - 안내 `이미지를 드래그하거나 클릭하여 업로드` / `JPG, PNG 지원 · 최대 10MB`
  - **`이미지 재선택`** 버튼(정상 업로드 시 활성) → 삭제 후 초기 대기 상태 복구
- **카메라 배치 (Map_002_02)** — 목록 상단 `선택 수/위치 카메라 수` (예 `3/7`)
  - (a) 카메라 항목 `+` → 도면에 마커 **자동 생성/배치**, `+`→`-` 전환
  - (b) 카메라 항목을 **도면으로 드래그 앤 드롭** → 해당 좌표에 즉시 배치
  - `-` → 마커 삭제, `-`→`+` 원복
  - 도면 위 마커는 **드래그로 좌표 변경 가능**
  - **위치명 호버 시 `X` 노출** → 선택 시 마커 삭제 + 목록 버튼 `+`로 원복

### 3-4. 맵 수정 (Map_003)
- 타이틀 `맵 수정` + `취소`(변경 시 편집 취소 alert) / `완료`(필수값 충족 시 활성)
- 기존 정보·마커 좌표 수정 가능 (예시 `7/7`)

## 4. 알림 (Alarm_001 / popup_01 / popup_02)

### 4-1. 알림 목록
- 타이틀 `알림 목록` + **`관심인물 관리`** 버튼(→ 팝업)
- **일자별 그룹핑 헤더 `YYYY-MM-DD`**, 최신순, 최초 진입 시 최신 자동 선택
- 알림 카드: 영상 대표 썸네일, **알림명**(`관심인물 포착`), 인물 식별명, **분류**(`용의자`), 위치명, 카메라명, 포착일시
  - 예: `2층 로비/택배 보관함・cam 01-234`, `2026-01-04 00:12:40`
- **미확인 알림 카드 하이라이트**, 선택 시 **읽음 상태로 전환**

### 4-2. 알림 상세
- 타이틀 `알림 상세` + `원본 보기`(영상 상세로 이동) / `사건 등록`(팝업)
- 영상 영역: 대표 썸네일, 대상명, 장소명, 카메라명, 출현 일시

### 4-3. 관심 인물 관리 팝업 (3 상태)
**(a) 목록** — 타이틀 `관심 인물 관리`, 안내 `알림 받을 인물을 등록 · 관리할 수 있습니다.`
- `관심 인물 (N)` + 검색(이름)
- `전체 선택` / **정렬 드롭다운(`등록일순`(Default) / `이름순`)** / `선택 삭제`(1개 이상 선택 시 활성 → 인물 삭제 alert)
- 인물 카드: 체크박스, 식별명, 분류, **알림 유형**(`상시 알림`), 등록 일시
- 0건: **`등록된 관심 인물이 없습니다.`**
- 카드 선택 → 인물 상세로 전환

**(b) 상세** — `뒤로가기`(**검색어·정렬·스크롤 위치 유지**) + 타이틀 `관심 인물 상세`
- `이미지 (N)` 포착 영상 수 + 대표 썸네일
- 정보: 식별명, 분류, 등록 사유, 실시간 알림
- 버튼: `수정`(→ 수정 팝업) / `삭제`(→ 인물 삭제 alert)

**(c) 수정** — `뒤로가기`(변경 시 등록 취소 alert) + 타이틀 `관심 인물 수정`
- `이미지 (N)` — **다른 썸네일 선택 시 대표 이미지 변경**
- 입력: 식별명*, 분류(용의자/침입자/실종·보호대상/VIP/기타), 등록 사유*, 실시간 알림(상시 사용/미사용/**스케줄 설정**)
- `취소`(변경 시 등록 취소 alert) / `완료`
